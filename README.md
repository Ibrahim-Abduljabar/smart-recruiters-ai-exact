# Smart Recruiters AI — النسخة الخارجية

صفحة هبوط مبنية بـ HTML و CSS لعرض فكرة Smart Recruiters AI للمستخدمين. 
تهدف لتقديم نظرة واضحة عن قدرات النظام وكيف يساعد فرق التوظيف في اتخاذ قرارات أفضل.

- شرح طريقة عمل النظام

- تصميم عربي خفيف وسريع
